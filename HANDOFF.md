# Umoja Website Handoff

This package contains the current static website for Umoja Multipurpose Cleaning Services.

## Current State

- The site has been split into separate pages: Home, About, Services, Work, Clients, Careers, and Contact.
- The homepage uses the owner-at-work window cleaning photo as the landing image.
- Listing photos have been copied into `site/assets/` and are used across the site.
- The Clients page was restyled so it opens with a light hero section, followed by testimonials, partner logos, and a real-photo gallery.
- Testimonials use avatar initials instead of real-person photos.
- The Google listing rating currently shown is 4.9 from 9 reviews.

## Main Files

- `site/index.html` - homepage
- `site/about.html` - company story and values
- `site/services.html` - service pages and FAQ
- `site/work.html` - work categories and process
- `site/clients.html` - testimonials, partners, and listing photos
- `site/careers.html` - job application page
- `site/contact.html` - contact and quote paths
- `site/styles.css` - visual styling
- `site/script.js` - navigation, slider, reveal animations, and work tabs

## Preview

Open `site/index.html` in a browser to view the website locally.
